# 要件定義書

## 概要

自分の思い出や日常の瞬間を写真として投稿し、コメントを添えて個人アルバムのように保存できます。写真のアップロードやコメント入力など、さまざまな便利な機能を簡単に使えます。

構成は以下のとおりです：

- **バックエンド**：Django（REST API）
- **フロントエンド**：React
- **対象環境**：PCブラウザ向け

## 機能要件
- ユーザー登録（管理者のみ。サインアップ画面は作らず、Postman などから API で登録する）※改修案件2
- ログイン
- ログアウト
- スナップの一覧表示（自分の投稿だけ・新しい順。下までスクロールすると 12 件ずつ続きを読み込む）※改修案件1・4
- スナップの新規登録
- スナップの削除
- スナップの更新（コメント・タグ）
- ファイルの新規登録
- ファイルの削除
- タグ付け（1 つのスナップに自由なタグを付ける。一覧をタグで絞り込める）※改修案件3

## 非機能要件
- デバイス：PC想定（初期開発ではレスポンシブデザインを考慮に入れない）
- CORS設定：React（別ポート）からのAPIアクセスを許可（`http://localhost:3000` のみ、Cookie の送信あり）
- 画像保存：ローカル
- 認証方式：トークンベース（JWT）。トークンは HttpOnly Cookie に保存し、CSRF 対策を行う ※改修案件1
- 画像の制限：jpg / jpeg / png / gif / webp、最大 5MB / 枚 ※改修案件2
- 入力の制限：コメント 1000 文字まで、タグは 1 つのスナップに 10 個・1 つ 30 文字まで ※改修案件2・3
- 入力チェック：フロントとバックの両方で行う ※改修案件2
- 表示言語：日本語対応

## 改修の記録
- 改修の計画と記録は [docs/05_改修案件/](../05_改修案件/) にまとめている。
  
## 使用技術
- Django（バックエンド）
- React（フロントエンド）
- SQLite（初期DB）

## 使用ツール・サービス
- バージョン管理： GitHub
- APIのテスト： Postman
- Python仮想環境：venv
- 開発用エディタ： VSCode
- VSCodeの拡張機能
  - Open API
  - Markdown All in One

## 備考
- 初期バージョンでは「いいね」や「フォロー」機能は搭載しません。
- 投稿へのコメント機能は省略予定（コメントはSnapに付随する形で投稿時にのみ入力）。
