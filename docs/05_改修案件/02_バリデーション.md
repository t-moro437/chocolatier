# 改修案件2：バリデーション（画像・コメント）とサインアップの権限

- 対象：Chocolatier（backend: Django + DRF / frontend: React + TypeScript）
- 作成日：2026-09-29
- 状態：完了（自動チェック・ブラウザ確認とも完了）
- 元の計画：[01_認証_バリデーション_タグ_無限スクロール.md](01_認証_バリデーション_タグ_無限スクロール.md) の「案件 2」
- 解説記事：[docs/03_articles/08_validation.md](../03_articles/08_validation.md)

## 1. 背景
| # | 課題 | 該当箇所 |
|---|------|----------|
| 1 | 要件定義書の「画像サイズ制限：最大 5MB / 枚」が未実装。画像以外のファイルもアップロードできる | `serializers.py`, `FileInput.tsx` |
| 2 | コメントの文字数に上限がない | `serializers.py` |
| 3 | API のエラーが画面に出ず、コンソールにしか表示されない。ファイル未選択は `alert` | `SnapshotPage.tsx` |
| 4 | サインインに失敗しても、画面に何も出ない | `SignInPage.tsx` |
| 5 | サインアップ API が、ログインなしで誰でも呼べる | `views.py` の `UserSignup` |

## 2. 決定事項
| 項目 | 方針 |
|------|------|
| 画像 | jpg / jpeg / png / gif / webp の 5MB 以下。Backend は Pillow で中身が画像かも確認する |
| コメント | 最大 1000 文字（シリアライザーで制限。マイグレーションなし） |
| チェックする場所 | フロントとバックの両方。上限値は両方でそろえる |
| エラーメッセージ | 日本語（`LANGUAGE_CODE='ja'`） |
| サインアップ画面 | **作らない** |
| サインアップ API | 運用（Postman からのユーザー作成）のために残し、**管理者だけ**（`IsAdminUser`）にする |

### 元の計画（01）からの変更点
| 項目 | 01 の計画 | 実際 | 理由 |
|---|---|---|---|
| サインアップの入力チェック（email の重複・パスワードの強さ） | 実施する | **対象外** | サインアップ画面を作らないため |
| サインアップ API の権限 | 記載なし | **管理者だけにする** | 誰でも呼べる状態を塞ぐため |
| 選択ダイアログの絞り込み | `accept="image/*"` | `accept=".jpg,.jpeg,.png,.gif,.webp"` | `image/*` だと `.bmp` なども選べて、Backend とずれるため |

## 3. 対応内容

### Backend
| ファイル | 内容 |
|---|---|
| `requirements.txt` | `Pillow==12.3.0` を追加。UTF-16 から UTF-8 に保存し直した |
| `chocolatier_core/settings.py` | `LANGUAGE_CODE = 'ja'`。上限値の定数 `MAX_UPLOAD_SIZE` / `ALLOWED_IMAGE_EXTENSIONS` / `MAX_COMMENT_LENGTH` を追加 |
| `chocolatier_api/serializers.py` | `SnapCreateSerializer`：`upload` を `ImageField` に変えて `FileExtensionValidator` を付け、`validate_upload` でサイズをチェック。作成・更新の両方で `comment` に `max_length` を付けた（`extra_kwargs`）。重複していた import を削除 |
| `chocolatier_api/views.py` | `UserSignup` を `IsAdminUser` に変更（認証はデフォルトの Cookie 認証を使う） |

### Frontend
| ファイル | 内容 |
|---|---|
| `src/utils/validators.ts`（新規） | 上限値の定数と、`validateImageFile` / `validateComment` |
| `src/utils/apiError.ts`（新規） | DRF のエラーを画面用の文章に変える `getApiErrorMessages`（例：「画像：画像サイズは5MB以下にしてください」） |
| `components/commons/FileInput/FileInput.tsx` | `accept` で拡張子を絞り、選択時とドロップ時にチェックしてエラーを表示。同じファイルを選び直せるようにした。ドラッグ中の枠が消えない不具合を修正 |
| `pages/SnapshotPage/SnapshotPage.tsx` / `.css` | 送る前のチェック、API エラーをモーダル内に表示、文字数カウンター（上限を超えると赤くなる）。`alert` を画面内のメッセージに置き換え |
| `pages/SignInPage/SignInPage.tsx` | 未入力とログイン失敗のメッセージを表示。使っていない `Link` の import を削除 |

## 4. 受入条件と確認結果

### 自動チェック（テスト用の一時 DB / 関数の単体実行で確認）
| 受入条件 | 結果 |
|---|---|
| 普通の png は作成できる | ✅ 201 |
| 5MB を超える画像は API で 400 | ✅ `画像サイズは5MB以下にしてください` |
| 中身がテキストの `.png` は API で 400 | ✅ `有効な画像をアップロードしてください。…` |
| `.bmp` は API で 400 | ✅ `ファイル拡張子 “bmp” は許可されていません。…` |
| 1001 文字のコメントは、作成・更新とも API で 400 | ✅ `この項目は1000文字より長くならないようにしてください。` |
| サインアップ API：未ログイン / 一般ユーザー / 管理者 | ✅ 401 / 403 / 201 |
| フロントの `validateImageFile` / `validateComment`（7パターン） | ✅ すべて期待どおり |
| フロントの `getApiErrorMessages`（400 / detail / 接続不可 / 500 / その他） | ✅ すべて期待どおり |
| TypeScript の型チェック | ✅ エラー 0 件 |

### ブラウザでの確認（2026-09-29 完了）
- [x] 5MB を超える画像を選ぶと、赤いメッセージが出てプレビューされない
- [x] `.bmp` や PDF をドロップしても、同じくメッセージが出る
- [x] ドロップした後、ドロップ枠の灰色が消える
- [x] 1001 文字以上でカウンターが赤くなり、保存するとメッセージが出る
- [x] サインインで、空のまま押したとき・パスワードを間違えたときにメッセージが出る
- [x] 中身がテキストの `.png` を投稿すると、Backend のエラーが画面に表示される

## 6. 運用メモ：サインアップ API の呼び方（Postman）
1. `GET /csrf/`
2. `POST /token/` に**管理者**の username / password を送る
3. `POST /chocolatier_api/signup/` に `username` / `email` / `password` を送る（`X-CSRFToken` ヘッダーが必要）

- `X-CSRFToken` を自動で付ける Pre-request Script は、[07_cookieAuth.md の「Postman で使うとき」](../03_articles/07_cookieAuth.md#5-postman-で使うとき) を参照。
